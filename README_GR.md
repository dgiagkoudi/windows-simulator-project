# Windows Simulator

Προσομοιωτής λειτουργικού συστήματος εμπνευσμένος από τα Windows 98, κατασκευασμένος με Vanilla JavaScript. Η εφαρμογή διαθέτει draggable παράθυρα, interactive desktop shortcuts, προσβάσιμο Start Menu και ένα chaotic popup alert system.

## Λειτουργίες

- Desktop environment εμπνευσμένο από Windows 98
- Interactive desktop shortcuts
- Δυναμικά draggable παράθυρα
- Dynamic Z-index window focus management
- Πλήρως λειτουργικό Start Menu
- Live system clock
- Chaos Engine με αυτόματη δημιουργία popups
- Fake critical system alerts
- Accessibility υποστήριξη μέσω πληκτρολογίου
- Υποστήριξη ARIA labels για screen readers
- Reduced motion accessibility support
- Responsive mobile layout
- Υποστήριξη Touch Events

## Τεχνολογίες

- HTML5
- CSS3
- JavaScript (Vanilla)

## Τοπική Εκτέλεση

1. Κλωνοποιήστε το repository

```bash
git clone https://github.com/dgiagkoudi/windows-simulator-project.git

cd windows-simulator-project
```

2. Εκτελέστε την εφαρμογή

Ανοίξτε το `index.html` στον browser σας.

## Λειτουργικότητα

Η εφαρμογή επιτρέπει:

- Άνοιγμα πολλαπλών παραθύρων
- Μετακίνηση παραθύρων στην επιφάνεια εργασίας
- Χρήση του Start Menu
- Ενεργοποίηση fake chaos events
- Δυναμικό κλείσιμο παραθύρων
- Πλοήγηση μέσω πληκτρολογίου

## Accessibility

Η εφαρμογή περιλαμβάνει:

- Keyboard navigation support
- ARIA accessibility attributes
- Συμβατότητα με screen readers
- Υποστήριξη Escape για κλείσιμο παραθύρων
- Focus state styling
- Reduced motion support μέσω `prefers-reduced-motion`

## Mobile Support

Βελτιστοποίηση για:

- Mobile συσκευές
- Touch interactions
- Responsive desktop scaling

## Chaos Engine

Το Chaos Engine δημιουργεί fake system errors και popup παράθυρα εμπνευσμένα από παλιά λειτουργικά συστήματα.

Παραδείγματα:

- Fake critical errors
- Virus simulation popups
- Recursive alert spawning
- Χιουμοριστικά system messages

- Draggable desktop icons
